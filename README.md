## 프로젝트 소개

Litmus는 [DMOJ](https://github.com/DMOJ/online-judge) 기반으로 개발된 전북대학교 컴퓨터공학부 온라인 저지 시스템입니다. 프로그래밍 과제, 알고리즘 문제 해결, 프로그래밍 대회 등을 지원합니다.

## 주요 기능

### 과제 · 대회 운영

- **과제(Assignments) / 대회(Contests) 분리 운영**: 용도별 순위 형식(과제용 · 대회용)과 오답 패널티 설정
- **지각 제출**: 과제에 한해 마감 이후 제출 기한을 별도 지정
- **실시간 순위표**: 시간 제한, 문제별 배점 관리
- **표절 검사**: [JPlag](https://github.com/jplag/JPlag) 연동 유사도 검사 및 리포트 확인
- **결과 내보내기**: 대회 결과 엑셀 다운로드, 참가자 제출 코드 일괄 다운로드

### 채점

- **지원 언어**: C, C++14/17/20, Java 8, Python 3, Text
- **테스트 케이스 기반 자동 채점**: 채점 데이터 파일 업로드, 테스트 케이스별 배점
- **분산 채점기**: 다중 채점기 연결 및 채점기 상태 페이지 제공

### 문제 관리

- **Markdown 기반 문제 지문**: LaTeX 수식(MathJax) 지원
- **문제 목록 CSV / 엑셀 다운로드**

### 계정 · 권한 · 보안

- **통합 로그인**: 자체 ID/PW 방식 및 JEduTools(Keycloak) SSO
- **로그인 보호**: 로그인 연속 실패 시 일정 시간 잠금
- **교수 · 조교(TA) 권한**: 문제 및 대회 단위 편집 권한 위임

### 사용자 환경

- **다크 모드**: 라이트 / 다크 / 시스템 기본값
- **패치 노트**: 서비스 변경 사항 안내
